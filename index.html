Key for Cascade Playback: Use the same frame rate, total frame count, start/end points, and playlist order across devices. Build all clips from a shared timeline. Matching encoding does not guarantee hardware frame synchronization.
Cascade Media Guidelines (Brief)
  • Shared timeline: Content for left/right projectors or each quadrant should come from the same source timeline, with matching frame rate, total frame count, duration, start/end points, and playlist order. Do not mix 25 fps and 30 fps.
  • Consistent encoding: Prefer MP4/H.264, 25 fps constant frame rate (CFR), progressive scan, and 8-bit yuv420p. Use consistent encoding settings and keyframe positions across clips in the same group.
  • Reduce decoding complexity: If cascade playback stutters, run a comparison test with simpler encoding settings and inspect the actual file properties. Do not judge a file by its name or encoding command alone.
  • Test in stages: Start with continuous playback on one device, then test dual-device cold start, synchronized playback start, file switching, and looping. Record stutter timestamps and anomaly counts.

4K 2×2 / 2+2 Cascade

Candidate canvas for targeted testing: 3840×2160, H.264 Level 5.1, 25 fps CFR; target bitrate about 10 Mbps, VBV maxrate 12 Mbps, GOP 50, B-frames 0, reference frames 1. These are staged-test candidates, not universal certification standards.

Note: Re-test each resolution, device model, firmware version, and USB/internal-storage playback path separately. Matching media settings do not guarantee stutter-free playback, seamless switching, or frame-accurate synchronization. Validate 1920×1200 prototypes separately.
